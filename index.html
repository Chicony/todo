Первичная настройка

Для работы необходимо создать GitHub Gist и получить токен доступа.

1. Создайте Gist

Перейдите на gist.github.com и создайте новый публичный Gist с именем файла family_data.json и содержимым {}

2. Получите токен

Создайте Personal Access Token на github.com/settings/tokens с правами gist

3. Введите данные
